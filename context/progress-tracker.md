## Architecture Decisions

- React Native (Expo) will be used for mobile development to maintain cross-platform compatibility and fast iteration
- Django + DRF will serve as the single backend authority for authentication, geofencing, and data integrity    
- PostgreSQL will be the primary structured database for all system entities
- Three.js will be used inside WebView for 3D rendering instead of Unity to reduce build complexity and improve maintainability
- 360° walkthrough system will be implemented using panorama-based navigation rather than full VR simulation   
- Geofencing will be handled primarily on-device with backend validation fallback to reduce latency
- Department is a nullable organizational layer above Building — it never affects geofencing, unlock logic, or asset associations. Deleting a department uses SET_NULL to preserve buildings.
